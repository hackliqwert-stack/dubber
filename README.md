# Dubber — озвучка видео на русском, бесплатно и локально

Расширение для Chrome + небольшая программа на вашем компьютере. Открываете видео на любом языке
(YouTube и ещё ~1000 сайтов), нажимаете кнопку — и слышите русскую озвучку, а оригинал тихо играет
на фоне. Без подписок, без облаков, без API-ключей: распознавание речи, перевод и голос работают
на вашей видеокарте.

**Многоголосая озвучка.** Программа различает говорящих по голосу: мужчин озвучивает мужским голосом,
женщин — женским, а разным людям даёт разные голоса. Текст перевода согласуется по роду
(«я был уверен» / «я была уверена»).

```
 звук видео → Whisper large-v3-turbo → кто говорит? → NLLB-200 → Silero TTS → русская дорожка
   (yt-dlp)     распознавание речи     пол + голос     перевод     голоса      куски по 20 с → расширение
```

## Как это работает

1. Расширение отправляет локальной программе адрес страницы.
2. Программа скачивает **звук** (yt-dlp) и обрабатывает его **намного быстрее реального времени**
   (≈×12 на RTX 3050: 15-минутное видео — за 70 секунд, 10-часовое — примерно за 50 минут). Озвучка
   начинается через 15–30 секунд и дальше всегда идёт с запасом вперёд, поэтому голос синхронен
   с картинкой, а перемотка работает: программа сразу перескакивает туда, куда вы перемотали.
3. Готовые куски расширение проигрывает синхронно с видео и приглушает оригинал.
4. Готовая озвучка хранится в кэше — второй просмотр того же видео мгновенный.

Если озвучка ещё не успела, видео само встаёт на паузу («Дожидаюсь озвучки…») и само продолжается.
Это можно отключить в настройках расширения.

### Живой режим

Для прямых эфиров и сайтов, откуда звук не скачать: расширение слушает звук вкладки и озвучивает
фразу за фразой с отставанием 5–10 секунд (как синхронный переводчик).

## Требования

| | Минимум | Рекомендуется |
|---|---|---|
| ОС | Windows 10/11 | Windows 10/11 |
| Видеокарта | NVIDIA, 4 ГБ видеопамяти (драйвер 525+) | 6 ГБ и больше |
| Память | 8 ГБ ОЗУ | 16 ГБ |
| Диск | 8 ГБ свободно | 30 ГБ (кэш озвученных видео) |
| Браузер | Chrome / Edge / Brave (Chromium 116+) | |

Без видеокарты NVIDIA всё тоже работает, но на процессоре и заметно медленнее реального времени.

## Установка

1. Скачайте архив проекта (**Code → Download ZIP**) и распакуйте в папку с коротким путём без пробелов
   и кириллицы, например `C:\Dubber`.
2. Запустите **`install.bat`**. Он сам поставит Python, библиотеки (≈1,5 ГБ) и модели (≈3,2 ГБ, один раз)
   и создаст ярлык «Dubber» на рабочем столе.
3. Откройте в Chrome `chrome://extensions`, включите **«Режим разработчика»**, нажмите
   **«Загрузить распакованное расширение»** и выберите папку `extension`.

## Использование

1. Запустите ярлык **Dubber** (чёрное окно должно остаться открытым).
2. Откройте видео, нажмите значок расширения → **«Озвучить это видео на русском»**.
3. Через 15–30 секунд видео заиграет с русской озвучкой.

Настройки в расширении:

- **Голос** — «Разные голоса для каждого персонажа» (по умолчанию) или один выбранный голос на всё видео.
- Громкость оригинала под озвучкой и громкость самой озвучки.
- Автопауза, пока озвучка не готова.

## Ограничения (честно)

- **Голоса.** Silero v4 — хороший синтез, но не «живой» актёр. Настоящих разных голосов пять
  (3 женских, 2 мужских); шестому и далее персонажу того же пола достаётся один из них с немного
  изменённой высотой и темпом. Модели уровня ElevenLabs требуют 8 ГБ видеопамяти и больше.
- **Перевод.** NLLB-200 заметно лучше простого машинного перевода, но слабее больших языковых моделей:
  термины и шутки могут переводиться буквально, «ты» и «вы» иногда чередуются.
- **Кто говорит** определяется по голосу. Два очень похожих голоса могут слиться в одного персонажа,
  а короткие реплики (до 1,5 с) приписываются предыдущему говорящему.
- **Музыка и пение** не озвучиваются; речь поверх громкой музыки распознаётся хуже.
- **Закрытые видео и DRM** (Netflix, курсы за логином) не скачиваются — для них есть живой режим.
- YouTube периодически меняет защиту; если озвучка перестала запускаться, обновите yt-dlp:
  `server\.venv\Scripts\python -m pip install -U yt-dlp` (или повторно запустите `install.bat`).

## Модели и лицензии

| Что | Модель | Размер | Лицензия |
|---|---|---|---|
| Распознавание речи | Whisper large-v3-turbo (faster-whisper) | 1,6 ГБ | MIT |
| Перевод | NLLB-200 distilled 1.3B (CTranslate2, int8) | 1,4 ГБ | **CC-BY-NC 4.0** |
| Русский голос | Silero TTS v4_ru | 40 МБ | **CC BY-NC-SA 4.0** |
| Пол говорящего | ECAPA-TDNN voice-gender-classifier (ONNX) | 16 МБ | MIT |
| Отпечаток голоса | WeSpeaker ResNet34-LM (ONNX) | 26 МБ | CC-BY 4.0 |

- Код проекта — MIT (см. `LICENSE`). Модели перевода и голоса разрешены только для **некоммерческого**
  использования; для коммерческого сервиса их нужно заменить.
- Программа скачивает звук только на ваш компьютер для личного просмотра и ничего никуда не отправляет.
  Соблюдайте условия сервисов, с которых смотрите видео.
- Расширение не размещено в Chrome Web Store: оно использует yt-dlp, а магазин такое не допускает.

## Для разработчиков

```
server/            Python-сервер (FastAPI) на 127.0.0.1:8765
  app/jobs.py        конвейер: окна ASR → говорящие → перевод → TTS → WAV-куски; приоритет там, где зритель
  app/asr.py         faster-whisper, пословные метки времени
  app/speakers.py    пол + отпечаток голоса → отдельный голос каждому персонажу
  app/translate.py   NLLB через CTranslate2
  app/genderfix.py   согласование рода в переводе (pymorphy3)
  app/tts.py         Silero + подгонка длительности и тембра (ffmpeg)
  app/live.py        живой режим (WebSocket + VAD)
extension/         расширение Manifest V3 (popup, content script, service worker, offscreen)
dev/               тестовые страницы (сервер отдаёт их при DUBBER_DEV=1)
scripts/           install.ps1 и проверочные скрипты
```

Запуск сервера вручную: `server\.venv\Scripts\python -m app.main` (`DUBBER_DEBUG=1` — подробный лог).

Проверки:

```
server\.venv\Scripts\python scripts\e2e_test.py <url видео>      # весь конвейер через HTTP API
server\.venv\Scripts\python scripts\test_genderfix.py            # согласование рода
server\.venv\Scripts\python scripts\test_textproc.py             # разбиение на фразы, подготовка текста
server\.venv\Scripts\python scripts\test_speakers.py a_m=a.wav b_f=b.wav   # пол и различение говорящих
```

Безопасность: сервер слушает только `127.0.0.1`, отклоняет чужие `Host` (защита от DNS-rebinding)
и все запросы на запись и WebSocket, пришедшие не от расширения.
